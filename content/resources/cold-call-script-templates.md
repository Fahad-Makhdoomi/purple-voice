Cold call script templates save you from starting with a blank page, but a script only works if it sounds like something a person would say. Below are six structures, each with a short example you can edit and a note on how to turn it into a prompt for an AI voice agent. Pick one, change the details, and test it before you call a real list.

A quick rule for all six: write for the ear. Short sentences, contractions, one idea at a time. If you would feel silly saying a line to a stranger, rewrite it.

## How to use these cold call script templates

Each template has three parts: the structure (what happens, in order), an example, and an AI adaptation. Replace anything in [brackets]. For the principles behind turning a script into a prompt, see [writing an outbound call script for AI agents](/blog/outbound-call-script-for-ai-agents) and the [fill-in-the-blank prompt template](/resources/ai-voice-agent-prompt-template).

### 1. The permission opener

Structure: introduce yourself, say why you called in one line, ask for 30 seconds.

> "Hi [Name], it's [Agent] calling from [Company]. I'm calling because you asked about [topic] on our site. Is now an okay time for a quick question?"

AI adaptation: tell the agent to stop after the question and wait. If the answer is no, it offers a callback time and ends politely. Never let it continue past a "not now".

### 2. The trigger-event opener

Structure: reference something real that happened (a form fill, a download, a listing enquiry), then ask one question about it.

> "Hi [Name], this is [Agent] from [Company]. You enquired about [property or product] yesterday, and I wanted to check whether you're still looking. Are you?"

AI adaptation: pass the trigger as a variable from your contact list (for example, the enquiry source) so each call opens with the real reason. Do not let the agent invent a reason when the field is empty; give it a fallback line instead.

### 3. The problem-question script

Structure: name a common problem for people in the prospect's role, then ask whether it applies.

> "Hi [Name], it's [Agent] at [Company]. A lot of [role] we speak to tell us [common problem]. Is that something you're dealing with?"

AI adaptation: list two or three problems in the prompt and tell the agent to choose the one that matches the contact's industry. Say "many" or "a lot of", not invented percentages.

### 4. The qualify-first script

Structure: short opener, then three to five questions in a fixed order, then a decision: book, transfer, or close.

| Step | Purpose | Example question |
|---|---|---|
| 1 | Confirm fit | "Are you the person who looks after [area]?" |
| 2 | Find the need | "What are you using for that today?" |
| 3 | Find the timing | "When are you hoping to have something in place?" |
| 4 | Find the authority | "Is anyone else involved in the decision?" |
| 5 | Decide | "Based on that, would a 15-minute call with [Name] help?" |

AI adaptation: ask the agent to record each answer for the summary, and to skip any question the person has already answered. The [lead qualification questions bank](/resources/lead-qualification-questions-bank) has more to choose from.

### 5. The book-the-meeting script

Structure: confirm interest, offer two specific times, confirm details, close.

> "Great. I have [day] at [time] or [day] at [time]. Which suits you better?"
> "Perfect, I'll send a confirmation to [email]. Is that still the right address?"

AI adaptation: connect the agent to your calendar so it offers real slots, and tell it to read back the date, time and email before ending the call. Purple Voice can book on Google Calendar.

### 6. The soft-close follow-up

Structure: for leads that said "maybe later" or did not answer last time. Reference the earlier contact, make no pressure, give an easy yes or no.

> "Hi [Name], [Agent] from [Company] again. We spoke briefly on [day] about [topic]. I wanted to see whether the timing is any better. If not, I'll leave you alone."

AI adaptation: give the agent the notes from the previous call so it does not ask the same questions twice, and tell it to mark the contact as do-not-call if the person asks to stop.

## Edits that improve any cold call script

- Cut the first sentence. If the opener starts with "I hope you're well", delete it.
- Replace features with a question. "We offer X" becomes "How do you handle X today?"
- Write the exit before the pitch. Decide what the agent says on "not interested", "send me an email" and "who is this?".
- Keep a single goal per call. Book a meeting, or qualify, or confirm interest. Not all three.

## Turning a script into an AI agent prompt

A short mapping you can follow for any of the templates:

1. Goal: one sentence describing what a successful call looks like.
2. Persona: name, company, tone (calm, plain, not pushy).
3. Opening line: the exact words for the first 10 seconds, since that is where wording matters most.
4. Questions: a list, not a script, with the order that matters.
5. Facts: what the agent may say about your product, kept in a knowledge base.
6. Rules: never invent prices, stop when asked, transfer to a human when the lead is ready.

Then test it. A script that reads well on paper often breaks on the first interruption, so call your own phone and push back.
