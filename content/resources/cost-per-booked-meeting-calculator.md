Your cost per booked meeting is the total cost of your calling activity divided by the meetings it produced. This page gives you the formula, a checklist of inputs, and two illustrative worked examples you can rebuild in a spreadsheet in ten minutes. All figures are invented for demonstration; replace them with yours.

If you want the wider return picture, pair this with the [AI calling ROI calculator](/resources/ai-calling-roi-calculator).

## The formula

**Cost per booked meeting = total calling cost / meetings booked**

Where total calling cost for the period is:

**People + software + phone and usage + data + management**

Use the same period (a week, a month) for cost and meetings.

## Input checklist

Gather these before you calculate:

| Input | Where to find it |
| --- | --- |
| Hours spent calling, by person | Calendar, time tracking or an honest estimate |
| Hourly or loaded cost | Salary plus overhead, or contractor rate |
| Software costs | CRM seat share, dialler, agent platform |
| Phone number rental | Provider invoice |
| Call usage minutes and rate | Provider invoice |
| AI usage costs, if any | Provider invoice |
| List or data costs | Data vendor invoice |
| Management and QA time | Estimate hours at their rate |
| Meetings booked | Calendar or CRM, counted in the same period |
| Meetings held | Calendar or CRM |

Phone-number rental and AI usage with Purple Voice are billed by those providers, not by Purple Voice, so include them from the provider invoice.

## Example 1: human caller (illustrative)

A small team has one rep calling part time.

| Item | Amount |
| --- | --- |
| Rep calling hours (80 hours x 25) | 2,000 |
| Dialler and CRM share | 120 |
| Phone usage | 90 |
| List cost | 200 |
| Management and QA (4 hours x 40) | 160 |
| **Total** | **2,570** |
| Meetings booked | 26 |
| **Cost per booked meeting** | **2,570 / 26 = about 99** |

## Example 2: AI voice agent (illustrative)

Same lead volume, handled by an agent, with a person reviewing transcripts and taking transfers.

| Item | Amount |
| --- | --- |
| Platform plan | 299 |
| Phone number rental | 10 |
| Call usage and AI usage | 350 |
| List cost | 200 |
| Review and handover time (10 hours x 40) | 400 |
| **Total** | **1,259** |
| Meetings booked | 24 |
| **Cost per booked meeting** | **1,259 / 24 = about 52** |

These examples show how the cost structure shifts, not what you will achieve. A weaker script, poor list or low answer rate would change either result. Measure your own numbers in a pilot; see the [AI calling pilot plan](/resources/ai-calling-pilot-plan-30-days).

## Go one step further: cost per held meeting

No-shows still cost you. Calculate:

**Cost per held meeting = total calling cost / meetings held**

If 24 meetings are booked and 18 are held, example 2 gives 1,259 / 18, about 70. Reminders and confirmations lower no-shows, which lowers this number without changing anything about the calling. See [appointment booking script templates](/resources/appointment-booking-script-templates).

## Add the sales side: cost per closed customer

Cost per meeting becomes meaningful when you connect it to closing:

**Cost per customer = cost per held meeting / close rate**

Example: cost per held meeting of 70 and a close rate of 20 percent gives a cost per customer of 350. Compare that with what a customer is worth in gross profit. If a customer gives 2,000 in margin, 350 is acceptable; if they give 300, it is not.

## Break-even check

**Maximum affordable cost per meeting = customer margin x close rate**

With a margin of 2,000 and a close rate of 20 percent, the ceiling is 400 per held meeting. Anything below leaves room for profit; anything above loses money.

## Spreadsheet layout

Create these columns for each week or month: calling cost items, total cost, meetings booked, meetings held, cost per booked, cost per held, close rate, cost per customer. Add one row per period so you can see trends instead of a single number.

## Common mistakes

1. Ignoring management and review time.
2. Counting only the software bill, not the people-time that remains.
3. Comparing cost per booked meeting without comparing meeting quality.
4. Using a short period with too few meetings. Twenty is a thin sample; use longer periods where you can.
5. Comparing against another company's benchmark instead of your own margin.
